### Project Description
THENGA ROYALE 🌴 — Because apparently, even coconuts deserve a beauty pageant. We use computer vision to judge their hairstyle, rank their foliage, and crown the most unnecessarily fabulous coconut. A problem nobody asked us to solve.
### The Problem (that doesn't exist)
Who decided that coconut trees need a hairstyle ranking? Nobody. But we did.
There is no actual problem being solved—we deliberately created an unnecessary problem: determining which coconut tree has the best hairstyle.
### The Solution (that nobody asked for)
We built a computer-vision-powered coconut beauty pageant. The system analyzes uploaded coconut-tree images, evaluates their foliage based on volume, spread, symmetry, and wind style, calculates an overall score, and ranks them to crown Mr. Coconut 2026.

## Technical Details
### Technologies/Components Used

Languages: Python, TypeScript
Frontend: Next.js, React, Tailwind CSS
Computer Vision: OpenCV, NumPy
Backend/API: Python serverless API
Database: Supabase PostgreSQL
Image Storage: Supabase Storage
Deployment: Vercel
Development Tools: VS Code, Git/GitHub

### Project Documentation
For Software:
THENGA ROYALE is a computer-vision-based coconut beauty pageant. Users upload coconut-tree images, which are validated and analyzed using Python, OpenCV, and NumPy. The system calculates Hair Volume, Hair Spread, Symmetry, and Wind Style scores, generates an overall score, and ranks all contestants on the leaderboard.
The application uses Next.js and React for the interactive interface, Supabase for database and image storage, and Vercel for deployment.
